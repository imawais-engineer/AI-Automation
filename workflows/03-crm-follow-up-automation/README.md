# CRM Follow-Up Automation

## Problem

Leads need consistent follow-ups but manual reminders get forgotten or missed. Sales teams lose track of where leads are in the pipeline.

## Solution

This workflow automatically:
1. Adds new leads to CRM
2. Creates follow-up tasks
3. Sends reminders
4. Updates pipeline stages
5. Tracks engagement

## Workflow Steps

```
New Lead in CRM
    ↓
Create Follow-up Task
    ↓
Send Day 1 Follow-up Email
    ↓
Schedule Day 3 Call Reminder
    ↓
Schedule Day 7 Follow-up Email
    ↓
If No Response: Route to Manager
```

## Tools Used

- **Zapier, Make, or n8n** – Workflow orchestration
- **HubSpot or Pipedrive** – CRM
- **Airtable** – Task tracking
- **Gmail** – Email delivery
- **Google Calendar** – Scheduling
