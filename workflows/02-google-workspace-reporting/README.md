# Google Workspace Reporting Automation

## Problem

Weekly or monthly reports require manual data collection and compilation, taking hours to put together. You need a reliable, repeatable process.

## Solution

This workflow automatically:
1. Collects data from Google Sheets or Forms
2. Generates a professional Google Docs report
3. Saves it to Google Drive
4. Sends it via email automatically

## Workflow Steps

```
Scheduled Time (Weekly/Monthly)
    ↓
Fetch Data from Google Sheets
    ↓
Generate Report in Google Docs
    ↓
Save to Google Drive
    ↓
Email Report to Stakeholders
    ↓
Log Execution
```

## Tools Used

- **Make.com or n8n** – Workflow orchestration
- **Google Sheets** – Data source
- **Google Docs** – Report template
- **Google Drive** – File storage
- **Gmail** – Email delivery
